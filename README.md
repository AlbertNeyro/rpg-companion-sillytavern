# RPG Companion for SillyTavern

A customizable RPG companion extension for SillyTavern that tracks player stats, scene information, inventories, present characters, relationships, and character thoughts in an interactive UI.

This is an **AI-powered project**. AI tools are used during development to assist with coding, documentation, debugging, and feature implementation. The project remains community-maintained, and AI-assisted changes are reviewed and integrated into the codebase.

## Features

- Player stats, skills, statuses, and attributes with live editing.
- Configurable Info Box for date, time, weather, temperature, location, and recent events.
- Present Characters panel with character-specific stats, relationships, custom fields, and thoughts.
- Adjustable Info Box and Present Characters panel sizes.
- Floating thought bubbles beside character avatars.
- Advanced inventory management with multiple storage locations.
- Per-swipe tracker data so each chat swipe keeps its own state.
- Automatic swipe detection and context-aware tracker updates.
- Custom themes including Cyberpunk, Fantasy, Minimal, Dark, Light, and custom styling.
- Configurable tracker fields, widgets, and sections.
- Optional immersive HTML/CSS/JS elements for roleplay scenes.

## Installation

In SillyTavern, open the Extensions tab, select **Install Extension**, and install from:

https://github.com/SpicyMarinara/rpg-companion-sillytavern

For this fork/repository, use:

https://github.com/AlbertNeyro/rpg-companion-sillytavern

## Configuration

Open the RPG Companion tracker editor from the extension UI. The Info Box and Present Characters sections include size controls that let you change their relative vertical space.

Changes are saved with the tracker configuration and apply to the main panel. On smaller screens, the layout automatically adapts to the available space.
